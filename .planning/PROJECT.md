# Desktop Recorder

A minimal Mac desktop recording app that lets you select screen regions and record with audio.

## Vision
Simple, elegant screen recording for Mac users who want quick captures without bloated software.

## Core Features
- Screen/window/region selection
- System audio + microphone capture
- MP4/MOV export
- Minimal, clean UI

## Tech Stack
- **Electron** - Desktop framework
- **React** - UI components
- **TypeScript** - Type safety
- **FFmpeg** - Video processing/encoding
- **Tailwind CSS** - Minimal styling

## Target Platform
- macOS (primary)
